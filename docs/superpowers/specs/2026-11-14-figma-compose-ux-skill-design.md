# Figma / Compose UX verification skill

The user wants reusable skills and scripts that connect Figma MCP and Code Connect to Compose generation, real screenshots, UI Automator, temporary tags and runtime probes, then assess implementation against UX intent. Deliver one discoverable orchestration skill and independently callable modules. A pixel comparison is one observation; it cannot establish interaction correctness or design-system reuse.

The package lives at `.agents/skills/figma-compose-ux/`. Keep the main SKILL.md concise; put schemas, connector/generation instructions, probe guidance and one runnable example in supporting files. Python scripts use standard library plus Pillow 12.0.0. They support offline exported evidence and live ADB collection; Figma MCP calls remain an agent connector step because tool namespaces vary. Discover actual tools and retain their source receipts. Do not fabricate MCP calls or a generic remote Code Connect endpoint.

Modules: design-contract preparation; reversible temporary instrumentation; runtime collection/parsing; physical-pixel/content-dp normalization; requirement assessment; pixel comparison; JSON/Markdown reports. Expose a single CLI with subcommands and importable functions. All artifacts carry schema version, build/capture identity and source provenance. Each requirement produces pass/fail/inconclusive/not_applicable and links design nodes, code mappings, runtime nodes and evidence. Report coverage and uncertainty rather than an opaque UX percentage.

Source generation is performed by the agent using the real project and verified Compose Code Connect mappings, then its project-supported build commands. The scripts validate evidence and safely manage explicit patches; they do not pretend to generate arbitrary Compose projects or inject modifiers into every composable via regex. Insets readout can live in a test APK. New testTag injection requires a temporary test build. Accessibility and unmerged Semantics remain different from a complete composition hierarchy.

No live Figma connector or real Compose application is available in this chat. The existing Android sample uses Views. Test the package with explicit synthetic fixtures, real subprocess/CLI tests, and fresh-agent application scenarios; label the live Figma-to-Compose integration unrun. Existing screenshot CI remains an independent regression check. Use the existing isolated cloud checkout; do not create a worktree or publish the cloud environment.

Control evaluation: five no-skill agents correctly rejected an unsupported 99% UX score, but produced five different report structures. The skill addresses reproducible artifact/command contracts with a positive recipe, not invented discipline failures. Mechanical safety/evidence checks belong in scripts and tests.
